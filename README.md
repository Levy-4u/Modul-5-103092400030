1. Pengertian Bootstrap [10 poin] 
Jelaskan apa itu Bootstrap dan apa kegunaannya!
Bootstrap adalah framework front-end open source yang menyediakan kumpulan kode CSS, JavaScript, dan komponen UI siap pakai seperti tombol, formular, navigasi, dan grid system yang memudahkan pengembang dalam membuat desain web yang konsisten dan responsif. Dengan Bootstrap, desain web secara otomatis menyesuaikan tampilan pada berbagai ukuran layar, mulai dari perangkat mobile hingga desktop.

3.	Grid dan Breakpoint [10 poin] 
Jelaskan mengenai class grid dan kegunaan breakpoint!
Grid digunakan untuk mengatur tampilan sesuai dengan ukuran layar dari perangkat, grid terdiri dari container, baris dan kolom. Sedangkan breakpoint untuk mengontrol kapan tata letak dapat disesuaikan pada ukuran viewport atau perangkat tertentu.

4.	Class Bootstrap [10 poin] 
Sebutkan minimal lima class yang disediakan oleh Bootstrap beserta kegunaannya!
      A.Container: Menyediakan pembungkus (wrapper) dengan lebar responsive yang berfungsi memusatkan konten di tengah halaman.

      B.row: Membuat sistem baris untuk pembungkus kolom dalam tata letak (grid sistem)

      C.text-center: Mengatur perataan teks menjadi rata tengah secara cepat pada elemen.

      D.col-md-6: Mengatur ukuran kolom pada grid sistem. Class ini membutuhkan kolom memakan setengah layar pada perangkat berukuran sedan ke atas.

      E.btn-primary: Mengubah elemen tombol atau tautan menjadi tombol standar berwarna biru khas Bootstrap.

5. Gambar Responsif [10 poin] 
Bagaimana cara agar foto atau gambar pada website responsif menyesuaikan ukuran layar perangkat?
Dengan menggunakan class img-fluid pada tag. Maka gambar akan otomatis mengikuti ukuran layar.
